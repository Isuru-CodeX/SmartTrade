## 2026-10-24 - Hardcoded Stripe Secret Key\n**Vulnerability:** Hardcoded Stripe API secret key found in `src/main/resources/app.properties`.\n**Learning:** Developer testing keys were inadvertently committed to the source configuration.\n**Prevention:** Store secrets as environment variables and use configuration templates (e.g., `app.properties.example`) rather than placing real or test secrets in version-controlled config files.
